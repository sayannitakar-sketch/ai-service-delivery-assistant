# AI-Powered Service Delivery Assistant

## Project Overview
This project explores how AI can support IT Service Delivery Management through structured incident analysis, SLA monitoring, operational risk identification, and management reporting.

The goal is to build a practical, beginner-friendly AI assistant using fictional service delivery data.

## Objectives
- Analyse incident trends and recurring issues.
- Identify actual and potential SLA breaches.
- Highlight operational risks and priorities.
- Generate clear weekly service delivery reports.
- Suggest actionable improvement recommendations.

## Tools
- ChatGPT
- Google Sheets
- GitHub

## Project Approach
This project will be developed step by step, starting with fictional incident data and prompt-based analysis.

## Data Privacy
All project data will be fictional. No confidential company, client, or production information will be used.
